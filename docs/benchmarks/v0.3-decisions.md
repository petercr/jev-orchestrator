# v0.3 decision snapshot baseline

Collected on 2026-10-16, 17:27:55–17:28:55 UTC. OpenAI Decisions matched the reference routing most often in this cohort. Direct TypeSafe Jev had the lowest observed decision latency. All 168 scheduled evaluations are retained, including two malformed Jev distributions. The production TypeSafe default and policy thresholds remain unchanged.

This is a small synthetic decision study: 14 distinct labeled states, three repetitions per model, and four fixed model/transport configurations. It measures routing under existing policy, not implementation quality or end-to-end coding performance. No issue reader, repository tool, validation command, coding worker, or approval loop was executed.

## Routing and policy outcomes

Correctness is membership in the predeclared reference action set. The failed-validation case permits either `READ_FILE` or `CALL_CODEX`; other cases have one reference action. Failed evaluations receive no correctness credit and remain in the denominator. Guarded correctness applies the actual policy and, for worker actions, the deterministic candidate selection/call-budget guard. It does not simulate file reads on virtual paths.

## Interpretation and limits

This cohort supports usable explicit routes under the existing enforcement layers and makes their intervention/latency tradeoffs visible. OpenAI had the highest reference-route matching; Clef had the lowest categorical action Brier; Jev was fastest. These are observations on this protocol, not a universal ranking or a reason to silently change the default.

The study uses one simple synthetic coding task with 14 workflow states and three repetitions each. It does not execute implementation, validate patches, measure actual operator alternatives, or test a complete live workflow. Provider preprocessing, transient load, caching, and network geography are not controlled. Brier/reliability metrics use only successfully normalized labeled answers, with small correlated samples. The release gate does not require a latency win; broader evidence and a separate decision would be needed to change the default.
