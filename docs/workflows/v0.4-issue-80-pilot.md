# v0.4 live issue #80 replay

This single candidate pilot replayed
[jspdf-md-renderer issue #80](https://github.com/JeelGajera/jspdf-md-renderer/issues/80)
with live TypeSafe/Jev evaluation and a real Codex worker. The issue was already
closed and the operator's checkout already contained uncommitted work, so the
run used an isolated clone of the committed, pre-fix state. Existing edits were
excluded and verified unchanged afterward.

This is one issue replay, separate from the matched baseline/candidate comparison
and reserved-task verification planned for v0.4. It does not complete that study.

## Limits

The two manual choices remain real routing detours; thresholds and provider
probabilities were not changed to hide them. The first patch passed validation,
so this run did **not** exercise the new failed-check repair exception. That
exception has offline regression coverage; a separate, budgeted repair scenario
is still needed for direct live evidence.

This replay demonstrates that the packaged candidate can complete this issue
with operator intervention. It does not establish a routing-quality improvement
over v0.3.1, compare providers, or evaluate the reserved verification task.
