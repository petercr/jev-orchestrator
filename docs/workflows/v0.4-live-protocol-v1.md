## Tasks and operator decisions

Exact task strings, initial files, instruction text, acceptance oracles, hashes,
and Git revisions are frozen by [study.mjs](../../scripts/workflows/study.mjs).
Neutral task directories and package names contain no cohort labels. Identical
tasks start at identical revisions. Neither historical issue #31 fixtures nor
its harness/results change.

The reserved `stable-tags` task implements string-only comma parsing: trim,
remove empty entries and duplicates, preserve first occurrence and case. The
four original examples are mandatory. Only `tags.mjs` and a new `tags.test.mjs`
may change. The repository declares `npm test` and `npm run lint` before launch.

The separately labeled repair task starts with an unconditional ellipsis bug.
Its first worker call must add empty, short, and exactly-ten-character regression
cases while leaving implementation unchanged and preserving the long-string
case. Inspect that staging before approving independent tests. After the real
failure, a second worker call may fix the implementation. If staging is ignored,
retain and label the deviation; never introduce a fault afterward. Only
`label.mjs` and `label.test.mjs` may change.

Review safe offered candidates as presented. At an `ASK_USER` stop with sufficient
context and implementation still needed, select the offered permitted worker,
then review and approve the resolved candidate. Do not switch workers, supply
fabricated clarification, or steer to manufacture a successful route. Approve
validation separately after each worker attempt. Choose an offered `FINISH`
only when fresh required checks, file scope, and original acceptance criteria
pass; then approve the resolved completion candidate. Confidence stays unchanged.

## Evidence and interpretation

The local evidence root is
`/home/peterc/.cache/dev-v04-comparison-d4vo29x8`. `prepare` writes a checksum-
protected `protocol.json`, fixture revisions, and all installed package file
hashes before collection. Launches check the helper, protocol, archive, package
files, pristine fixtures, and fixed order. A launch record is written before
spawning and cannot be reused. `inspect` records bounded scope and acceptance
checks outside AgentState; it cannot grant execution or completion. `report`
reads observations without provider or worker calls.

Report accepted patches separately from approved loop completion. Acceptance
requires the original behavioral oracle, allowed file scope, and fresh
current-generation independent test/lint evidence. Report iterations, worker
calls, manual alternatives, approvals, failed validation, evaluation recovery,
and phase timings from actual traces. Preserve nulls for absent evidence. Keep
prompt waits separate from active time. No token/cost estimates or causal speed
claims are justified by this pilot. The repair exception is exercised only if
actual scores and policy evidence show it; a repair that succeeds through a
different allowed route does not prove that exception was needed.

Reproduction uses the frozen artifacts, not a fresh install of mutable aliases:

```bash
pnpm env:run node scripts/workflows/study.mjs run /path/to/frozen-study r01 --live
node scripts/workflows/study.mjs inspect /path/to/frozen-study r01
node scripts/workflows/study.mjs report /path/to/frozen-study
```

Repeat launches are intentionally refused. A new cohort requires a new protocol
and recorded budget; it cannot replace this cohort's failed observations.
